# Rumo

App de tarefas com captura rápida, modo foco, widgets no Android e bandeja no Linux. Feito em Flutter.

## Rodar

```bash
flutter run -d linux
```

```bash
flutter run -d android
```

## Testar

```bash
flutter test
```

## Documentação

Arquitetura, widgets, recursos do Linux, ícone e roteiro ficam em [`docs/`](docs/README.md).
